# سامانه یکپارچه پایش زمین و اقلیم ناسا

نسخه Django دوزبانه فارسی/انگلیسی برای کشف محصولات NASA Earthdata، دریافت سری زمانی NASA POWER، جست‌وجوی Granule، دانلود انتخابی و بررسی ساختار فایل‌های علمی.

> این پروژه مستقل است و محصول رسمی ناسا نیست. برای استفاده علمی، راهنمای محصول، واحدها، تفکیک مکانی/زمانی، عدم‌قطعیت و پرچم‌های کیفیت منبع اصلی را بررسی کنید.

## نصب سریع در ویندوز

1. فایل ZIP را در یک مسیر مثل `C:\NASA\nasa_unified` استخراج کنید.
2. Python 3.11 نسخه 64 بیتی را نصب کنید و گزینه Add Python to PATH را فعال کنید.
3. فایل `run_windows.bat` را اجرا کنید.
4. مرورگر را در نشانی `http://127.0.0.1:8000/` باز کنید.

در اجرای اول، محیط مجازی ساخته می‌شود، وابستگی‌های اصلی نصب می‌شوند، فایل `.env` ایجاد می‌شود، دیتابیس راه‌اندازی می‌شود و سرور محلی اجرا می‌شود.

## قابلیت‌های فعلی

- NASA POWER واقعی: داده ساعتی، روزانه، ماهانه و اقلیم‌شناسی در حد پشتیبانی سرویس؛ جامعه‌های AG، RE، SB و HY؛ حداکثر ۲۰ پارامتر در هر درخواست نقطه‌ای.
- نمودار سری زمانی، واحد مجزای هر پارامتر، آمار کمینه/بیشینه/میانگین و خروجی CSV.
- نقشه تعاملی برای انتخاب مختصات.
- جست‌وجوی زنده مجموعه‌داده‌ها در NASA CMR، صفحه‌بندی، فیلتر زمانی و Provider.
- جست‌وجوی Granule برای Collection انتخاب‌شده، فیلتر زمانی و کادر مکانی.
- دانلود فایل‌های انتخاب‌شده از دامنه‌های مجاز ناسا و DAAC با محدودیت حجم و توکن اختیاری Earthdata.
- بررسی فایل‌های CSV، JSON/GeoJSON، HDF5، NetCDF و GeoTIFF. برای خواندن همه قالب‌ها باید بسته‌های اختیاری نصب شوند.
- FAQ فارسی و انگلیسی و جست‌وجو در پرسش‌ها.
- مرکز مستقل FAOSTAT برای محصولات منتخب ایران در دامنه QCL؛ دریافت سروری، کش شش‌ساعته، نمودار سالانه و خروجی CSV؛ در خطای API هیچ داده ساختگی جایگزین نمی‌شود.
- پیمایش کاتالوگ CMR با هدر Search-After به‌جای page_num/offset برای جست‌وجوی عمیق.

جزئیات نسخه‌های هدف SMAP و MODIS و کارهای مهاجرت در فایل [DATA_CATALOG_FA.md](DATA_CATALOG_FA.md) آمده است.

## اتصال FAOSTAT

بخش FAO از سرور Django به API رسمی FAOSTAT متصل می‌شود تا به محدودیت CORS مرورگر وابسته نباشد. فهرست فعلی شامل ۹ محصول منتخب ایران در دامنه QCL است. پاسخ موفق تا ۶ ساعت cache می‌شود؛ برای دریافت اجباری از دکمه «به‌روزرسانی اجباری» استفاده کنید. داده FAOSTAT هنوز در جدول پایدار دیتابیس آرشیو نمی‌شود و در صورت قطع سرویس، برنامه صریحاً خطا نشان می‌دهد.

## نصب خواننده‌های علمی

برای بررسی ساختار و نمونه آمار فایل‌های HDF5، NetCDF، GeoTIFF و CSV:

```powershell
.\.venv\Scripts\activate.ps1
pip install -r requirements-geospatial.txt
```

اگر نصب Rasterio یا یکی از وابستگی‌های مکانی روی ویندوز با خطا مواجه شد، برنامه اصلی همچنان کار می‌کند؛ فقط خواندن آن قالب غیرفعال خواهد بود.

## فعال‌سازی دسترسی Earthdata

1. حساب NASA Earthdata بسازید: https://urs.earthdata.nasa.gov/
2. توکن Bearer را طبق راهنمای رسمی دریافت کنید.
3. مقدار آن را فقط در فایل `.env` سمت سرور وارد کنید:

```env
NASA_EARTHDATA_TOKEN=YOUR_TOKEN
```

4. سرور را مجدداً اجرا کنید.

توکن را در HTML/JavaScript قرار ندهید و در Git یا پیام عمومی منتشر نکنید.

## اجرای دستی

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
python manage.py check
python manage.py migrate
python manage.py test
python manage.py runserver
```

## محدودیت‌های مهم علمی و فنی

- کاتالوگ CMR فراداده را جست‌وجو می‌کند؛ مشاهده Collection به معنی عمومی‌بودن دانلود همه فایل‌های آن نیست. بعضی محصولات به Earthdata Login یا سرویس اختصاصی نیاز دارند.
- این نسخه محصولات SMAP و MODIS را در CMR کشف و گرانول‌های آن‌ها را جست‌وجو می‌کند. هنوز الگوریتم علمی اختصاصی برای تمام خانواده‌های محصول SMAP/MODIS پیاده‌سازی نشده است.
- خواننده HDF5/NetCDF نمونه آمار و metadata را استخراج می‌کند و در صورت وجود scale factor و fill value در متادیتا آن‌ها را برای آمار نمونه لحاظ می‌کند؛ اما QA bitmask، الگوریتم بازیابی، reprojection و تفسیر علمی هر محصول باید جداگانه و براساس مستندات نسخه همان محصول پیاده‌سازی شود.
- این نسخه ۱۰ پارامتر رایج POWER را در فرهنگ محلی توضیح می‌دهد؛ کدهای پارامتر دیگر نیز در صورت معتبر بودن برای جامعه و تفکیک زمانی انتخابی قابل ارسال‌اند. فهرست کامل پارامترها را در [NASA POWER Parameter Dictionary](https://power.larc.nasa.gov/parameters/) بررسی کنید.
- برای جلوگیری از درخواست‌های بسیار بزرگ، بازه ساعتی به ۳۱ روز، روزانه به ۷۳۰۰ روز و ماهانه به ۱۸۲۵۰ روز محدود شده است.
- دانلود سروری در حالت پیش‌فرض به ۱۰۰ مگابایت برای هر فایل محدود است. برای آرشیوهای حجیم از گردش‌کار رسمی مراکز داده ناسا استفاده کنید.
- نسخه فعلی برای اجرای محلی/تیمی اولیه است؛ پیش از انتشار عمومی باید احراز هویت، مجوزها، محدودیت نرخ، صف پردازش، گزارش رویدادها، نگهداری فایل و تنظیمات Production اضافه شود.
